📸 Travelgram
Travelgram é um projeto de front-end que simula uma rede social de viagens, inspirado no Instagram. O objetivo é apresentar destinos turísticos com uma interface moderna e responsiva, utilizando HTML e CSS puros. 
Projeto feito durante o curso front-end da Rocketseat.

🧰 Tecnologias Utilizadas
HTML5: Estruturação do conteúdo.

CSS3: Estilização e layout responsivo.
